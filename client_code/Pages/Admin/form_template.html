Set up the station

  1. On a computer with an NVIDIA GPU, install Python 3.10, PyTorch with CUDA, lingbot-map and (for surfaces) Open3D: 
    conda create -n logsteps python=3.10 -y
conda activate logsteps
pip install torch --index-url https://download.pytorch.org/whl/cu128
git clone https://github.com/Robbyant/lingbot-map
pip install -e ./lingbot-map open3d
  2. Download logsteps_station.py (also in the repo's station/ folder, with a README).
  3. Run it with the key:Test the connection without a GPU by adding --fake --once.
